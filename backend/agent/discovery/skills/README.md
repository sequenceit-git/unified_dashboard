# Product Discovery 2 Agent Skills

Four focused, high-impact skills governing the 3-stage agentic loop:

1. **`product-discovery-search`**: Formulate search queries across target marketplaces (eBay, Temu, Amazon, Walmart) to discover 15–25 high-velocity product candidates.
2. **`cross-market-validation`**: Cross-reference each candidate across competing platforms to verify review volume, ratings, and defect flags.
3. **`sourcing-and-unit-economics`**: Discover cheaper wholesale/supplier buy links (AliExpress, 1688, Temu) and calculate landed net profit margins (Price - Sourcing - 15% Fees).
4. **`opportunity-scoring-rubric`**: Apply deterministic 0–100 rubric balancing profit margin (40%), demand velocity (35%), and customer review rating (25%).
