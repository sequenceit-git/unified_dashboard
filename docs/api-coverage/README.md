# Shop API coverage

Every official seller API endpoint of eBay, TikTok Shop and Temu, checked against the calls the dashboard's code makes (`backend/marketplaces/<shop>/`). Generated by `npm run api-coverage` (backend) from `catalog/` and `gaps/`; do not edit by hand.

Access (shops with a recorded app): **available now** — the shop's app already holds the scope; **needs scope** — the app must be granted that scope first. Within each section, gaps available now come first.

Statuses: **covered** — called; **covered (older version)** — called at an older API version; **missing** — a seller endpoint not called yet (each has a gap note); **not for sellers** — buyer, creator or partner APIs, never a gap.
